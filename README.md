One line (144 characters) reviewing my own Monday: the alarm snoozed itself, the bus left without me, and standup spent forty minutes scheduling a meeting about the next meeting. Entry for "Monday, Reviewed in One Line" on make.fun ($2, top five paid). The program writes the review to `entry.txt`; the line is the whole entry — no title, no explanation.

## Run it

```sh
python3 main.py
```

For a local run, point the output somewhere safe first:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output.
